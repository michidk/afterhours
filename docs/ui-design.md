# Interface direction

The entry menu uses the same dark teal, amber, condensed headings and block character models as the game. A compact left menu keeps choices together; a sunset rooftop and layered skyline give the character a place in Paloma. Amber build selection and pale focus rows and native inputs keep keyboard focus clear.

References inspected:

- [GTA V combat HUD](https://upload.wikimedia.org/wikipedia/en/5/5c/Grand_Theft_Auto_V_combat.jpg): corner information and an unobstructed center.
- [Red Dead Redemption 2 interface gallery](https://interfaceingame.com/games/red-dead-redemption-2/): strong menu hierarchy and restrained gameplay overlays.
- [NativeUI](https://github.com/Guad/NativeUI): compact rows, selected states and footer controls. This is a community Rockstar-style menu library, not an official GTA screenshot.

The HUD retains its minimap, chat, player list, location and palette. Permanent hints now point to Map and Controls; walking no longer displays a vehicle speed of zero. Debug help appears only when enabled by the server.

Installed shared skills: [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) and [Vercel web-design-guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines). Canonical user skills are linked into both Codex and Claude Code.
